# 生图模式

在 Agent（或设置）页顶栏点击「生图模式」，切换到独立图片对话；「切回编码」回到原来的编码页。创作模式隐藏文件、Git、终端导航，不改写 Agent 的模型与会话。

## 已实现

- 提示词、独立服务 / 模型选择（复用已保存服务密钥），自动尺寸和兼容尺寸选择。
- 1–4 张逐张生成，每张单独请求并可能计费；单张点击发送即提交，输入框旁明确提示计费，多张提交前额外确认，失败不自动重试。
- 聊天式时间线按「描述 → 图片回复」展示；同次多张只展示一个描述气泡，不合并不同请求中相同的描述。成功清空输入，失败/停止保留描述；「复用创作」回填原描述和参数，不会自动发送。旧作品兼容读取。
- 等待耗时、已完成张数、停止等待；已收到图片即使恰好停止也完成本地保存。
- 本地作品列表、提示词和参数复用、图片预览与系统「保存原图」位置选择。
- 创作元数据与草稿在应用私有 `files/image-studio/`，原图在生成时工作区的 `generated-images/`。
- 创作请求直接使用 `/images/generations`，不发送 Agent 工具、聊天历史或思考参数。

## 能力边界

尺寸支持与账号通道取决于服务端，模型列表仅说明 ID 存在，不保证生图可用。`1024×1536` 是 2:3，`1024×1792` 也并非精确 9:16。自动尺寸不承诺固定比例。

尚未核实的参考图编辑、质量、种子、负面提示词和视频接口不伪装为可用功能。首版返回专用生图客户端的实际错误，不失败后自动改接口、换模型或重试。

停止请求不能保证停止服务端生成或退款。进程被系统杀死后不自动恢复生成，避免重复计费；已保存作品仍可查看。

## 视觉接入

本次沿用现有 `ui/theme/Theme.kt` 的 Material 3 色彩、字体、间距及系统保存界面，不改造编码界面视觉。界面使用单一图片对话时间线，底部固定多行输入框和发送/停止按钮并避让键盘；模型入口在上方，画幅和张数摘要在输入框旁，完整服务/模型/尺寸/张数收进底部设置面板。生成图直接提供「查看大图」「保存原图」，无需先打开附件弹窗。详细传输诊断折叠到作品详情中，沿用应用主题，不把图片编码作为正文展示。

这是聊天式交互，不是 Gemini 原生协议或连续修图适配：仍通过现有 `/images/generations` 独立请求，不发送上一张图片或对话历史，也不伪装支持「把上一张背景换掉」等参考图编辑。界面改造本身不承诺提升服务端传输速度。

## 专业创作布局

- 手机保留图片对话，输入台整合画幅、张数与输出参数；长描述默认四行，可展开。
- 840dp 以上展开右侧参数检查栏，复用服务/模型/尺寸/张数组件。
- 空态模板填入可编辑的构图描述，不直接触发生成；历史定位按作品 ID 并考虑前置通知。
- 完整视觉规范见 `DESIGN.md`；没有新增视频、参考图编辑等未经验证的接口能力。

## 创作模板与模型筛选

- 输入台「打开创作模板」随时可用，空白对话另有「浏览创作模板」。内置 12 种模板：商品棚拍、品牌海报、人像写真、角色设定、叙事插画、室内概念、美食大片、电影感场景、应用图标、时尚大片、表情贴纸与材质研究；支持分类与关键词组合搜索。模板为本地创作配方，并非外部工具的官方模板。
- 推荐尺寸对标准 DALL-E 2/3 做已知尺寸映射，其他模型仍由服务端决定兼容性。应用前显示实际推荐尺寸。
- 等待时展示按输出画幅的低对比模糊画布，并标注占位而非实时预览；后台与系统关闭动画时停止循环。真实图片收到后，使用其缩小采样图平滑显影为清晰预览（650ms），仅当前生成结果播放一次，不延迟保存或再次请求网络。Android 12+ 叠加递减模糊，旧版以低清采样过渡；遵循系统动画时长设置。不宣称支持 Grok 原生的中间生成帧。
- 模板可编辑主体、风格、构图等字段，并预览组合后的提示词。使用模板只替换描述与推荐画幅，不发送请求，不修改模型或张数；已有草稿需确认替换。
- 模型列表独立读取创作页所选服务，默认按名称筛出生图候选，支持搜索、「查看全部模型」与手动 ID。名称识别不证明接口权限或可用通道，不通过收费生图探测能力。
- 创作模型发现不会修改编码 Agent 模型；切换服务时清除旧列表并忽略迟到结果，未允许网络时不发查询。

## 在线提示词目录

模板中心分为「本地配方」和「在线提示词」。在线目录读取 YouMind OpenLab 的 `awesome-gpt-image-2` 与 `awesome-nano-banana-pro-prompts` 中文 README，按公开提示词原文提供搜索、详情和编辑；不是自动导入执行的指令、工作流或插件。读取公开 GitHub 不发送服务密钥、用户草稿或图片，关闭面板/切换来源会取消网络请求，遵守应用联网权限。

- 首次读取按来源加载，当前面板内缓存；刷新由用户触发。每次读取最多 4 MiB，最多展示 500 条。目录条数以来源 README 为准，不声称同步网站全部内容。
- 保留作者、原始发布链接、仓库和 CC BY 4.0 许可入口；仓库同时声明社区内容仅供教育用途，具体素材、肖像及其他使用权需另行核对。不下载或打包第三方效果图，不把它们伪装为本应用生成结果。
- 填入前可以编辑原文；已有草稿须确认替换。仅替换提示词，不修改模型、画幅或张数，不自动产生生图请求。
- 来源模型分类不表示当前服务已验证兼容；当前没有参考图编辑能力，因此详情明确提示不要直接照用依赖参考图片的描述。
- 无网络、GitHub 限流、超时或格式变化时显示可恢复错误，保留本地模板入口；不自动重复调用图像接口。

## 等待诊断

- 区分等待服务响应、接收响应、下载原图、解析和本地保存。只有响应提供 Content-Length 时显示接收比例，不伪造服务端出图百分比。
- 等待超过 90 秒提示服务尚未返回图片，不能据此断言服务端故障。
- 默认网络调用等待响应最多 5 分钟、单次调用最多 6 分钟；单张含下载整体最多 7 分钟。超时会退出运行态，并提示先核对服务端记录，绝不自动重试。
- 响应 JSON/Base64 解析在 IO 线程执行，避免大图阻塞界面。超时与用户停止显示不同结果。
- JSON 响应使用有界、单次扫描的完整对象读取：完整 JSON 已到达时立即解析，不等待代理发送 HTTP 最后分块或关闭响应体。普通聊天非流式响应复用同一读取器；图片模型 SSE 收到终止 finish_reason 即完成，不再等缺失的 `[DONE]`。
- 接收阶段显示实际字节数与近期采样速率，折叠详情显示等待首字节与传输耗时；超过 3 秒无新数据时隐藏过期速率。生图客户端收到响应头后仍使用生成读取超时（默认 5 分钟），首次收到正文数据才切换为 60 秒空闲读取超时；因为部分代理会提前返回响应头，不能把响应头当作生成完成。单次网络调用最多 6 分钟的总限额不变。图片模型聊天请求整体也限制为 7 分钟，避免心跳无限续期。
- 接收速度改为近期采样（KiB/s），不再使用含等待的阶段累计平均值。首个正文块前的时间单独归为「等待首字节」，超过 3 秒无进度时不继续显示旧速率。
- 每张作品保存等待首字节、接收/下载与本地处理保存耗时、响应大小，不保存密钥、签名 URL 或 Base64；旧作品仍可读取。正文读取超时也显示明确原因，不再只显示 timeout。
- 2026-11-09 单次真实探测：gpt-image-2.6 等待响应头约 44.7 秒、接收 3,238,739 字节约 4.0 秒、本地解析保存约 0.15 秒，总计 48.84 秒。手机本地 4 MiB JSON 扫描 32 ms。本次未复现 7 KiB/s，不能据此断言此前请求或服务端一直正常。
- 后续实际慢请求的作品记录：等待首字节 45.80s、接收 2535 KiB 用时 298.79s、本地处理保存 0.07s。证明存在正文接收缓慢，不能用此前快请求否定。
- 新增正文 `InputStream.read` 阻塞耗时（不含首块等待），并记录 HTTP 协议；成功作品详情与失败提示均可看到传输诊断。读取耗时包括 TLS/解压/网络等待，不能仅凭它进一步认定具体服务节点故障。失败不输出含 URL/凭据的原始异常，只区分 DNS/TLS/连接/超时。
- 本地真实 HTTP 测试：4194422 字节 JSON 经生产客户端、进度回调与 StateFlow 接收解析约 176ms；另覆盖分段延迟读取归因。一次真实探测 9.75s 连接中断、未收到响应头，没有自动重试；不能据此承诺线上传输已修复。
- 这些改动让等待可诊断、可结束，不保证缩短模型服务本身的排队或生成时间。
